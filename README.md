# sfera-releases
Sfera — программа для учёта клиентов и записи для салонов красоты, спа-центров, тренажёрных залов, массажных кабинетов и бассейнов. Возможности: календарь записей, база клиентов и мастеров, финансовая отчётность с печатью отчётов, автоматические email-напоминания клиентам о записи. Установка на Windows. 
Лицензия — один компьютер, разовый платёж без подписки. После оплаты вы мгновенно получите лицензионный ключ для активации.
