# Sfera

Программа для учёта клиентов и онлайн-записи для салонов красоты, спа, фитнес-клубов, массажных кабинетов и бассейнов. Поддерживает сразу несколько направлений в одной программе.

![Главная страница Sfera](главная.png)

## Возможности

- **Главная страница** — ключевые показатели салона и график выручки по категориям
- **Онлайн-запись 24/7** через отдельную веб-страницу — с выбором мастера, автоподгрузкой заявок в календарь и уведомлением мастеру на email
- **Абонементы** — тарифы на фиксированное число занятий или безлимит, автосписание/возврат посещений, отдельный учёт в финансах
- **Карточки клиентов** — последний визит, услуга, статус (новый/активный/неактивный)
- Календарь записи, база клиентов и мастеров
- **Финансовая отчётность** с печатью и фильтрами по мастеру, клиенту, услуге и периоду
- Автоматические email-напоминания клиентам о записи
- Светлая и тёмная тема, свой логотип салона в интерфейсе
